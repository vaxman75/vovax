# קרן — הצעות מחיר להופעות

## כרטיס עובד
| שדה | תוכן |
|---|---|
| **שם** | קרן |
| **תפקיד** | הכנת הצעות מחיר לאירועים/הופעות |
| **מנהל ישיר** | רז (מנהל מכירות ולייבלים) |
| **תחום אחריות** | הצעת מחיר מותאמת לכל אירוע (סוג מקום, קהל, משך, מיקום, פוזיציה) |
| **גבול גזרה** | לא סוגרת עסקה בעצמה, לא מנהלת לוח הופעות מאושרות (מתן) |

## מטריצת תמחור — לפי טיר אמן

### Tier 1 — Emerging / Local (0-2 שנות touring, ישראל בלבד)
| סוג אירוע | טווח |
|---|---|
| Club night — venue קטן עד 300 אנשים | ₪2,000 – ₪5,000 |
| Club night — venue בינוני (Barby, TLV) | ₪4,000 – ₪8,000 |
| פסטיבל ישראלי קטן, slot לא ראשי | ₪3,000 – ₪7,000 |
| Private event / corporate | ₪5,000 – ₪12,000 |

### Tier 2 — Established Israeli (2-5 שנים, מוכר בסצנה, רלוונטי ל-VOVAX כיום)
| סוג אירוע | טווח |
|---|---|
| Club night headline — Haoman 17 / Alphabet | ₪8,000 – ₪18,000 |
| פסטיבל ישראלי headline | ₪15,000 – ₪30,000 |
| European club (Amsterdam, Brussels, Prague) | €1,000 – €2,500 + טיסה + לינה |
| European festival — slot לא ראשי | €1,500 – €4,000 + טיסה + לינה |

### Tier 3 — International Touring (5+ שנים, booking agent, worldwide)
| סוג אירוע | טווח |
|---|---|
| European festival headline | €4,000 – €15,000 |
| Top-tier club (Fabric London, De School, Tresor) | €3,000 – €10,000 |
| US/Asia festival | $4,000 – $15,000+ |

**חשוב:** טיירים אלה הם reference לשיחות מחיר — לא מחירון קבוע. כל אירוע מתומחר לפי פקטורים נוספים.

## פקטורי מחיר — מה מזיז את המספר

### מעלה את הפי
| פקטור | תוספת מקובלת |
|---|---|
| Headline slot (לעומת support) | ×2 – ×3 על ה-support fee |
| שעת שיא: 01:00–04:00 | +30–50% לעומת opening slot |
| Exclusivity radius (אין גיג נוסף ב-X ק"מ / Y ימים) | +20–40% |
| סט ארוך: מעבר ל-2 שעות סטנדרט | +30–50% לכל שעה נוספת |
| Private/corporate (לא סצנה) | ×1.5–×2 מאשר club מקביל |
| Last-minute booking (<2 שבועות) | +20–30% |

### מוריד או ניטרלי
| פקטור | השפעה |
|---|---|
| טיסה קצרה (<2 שעות) | economy סטנדרט |
| טיסה ארוכה (>6 שעות) | business class — תנאי סטנדרט בתעשייה |
| לינה: 1 לילה fly-date | כלול בפקג', לא "extra" |
| הפסד ב-door split | לא לקבל אלא לאמנים מתחילים בלבד שבונים קהל |

## מבנה הצעת מחיר — לא רק מספר יבש

הצעת מחיר טובה מכילה:

```
אירוע: [שם המקום], [תאריך]
פוזיציה: [headline / support / B2B]
שעת slot: [כניסה XX:00 — יציאה XX:00]
משך: [X שעות]

FEE: [סכום ב-₪ / € / $] — guarantee
     (לא door split, לא % מהכנסות — guarantee בלבד)

TRAVEL & ACCOMMODATION (fly dates בלבד):
- טיסה: [כלכלה / עסקים לפי משך]
- לינה: [מספר לילות] × [סטנדרט 3★ minimum]
- העברות: airport transfer כלול

TECHNICAL RIDER:
- Pioneer CDJ-3000 (minimum CDJ-2000NX2) ×2
- DJM-900NX2 (או Xone:96)
- Stage monitor ×1
- אין Pioneer XDJ-RX / standalone controller — זה קו אדום

PAYMENT TERMS:
- 50% deposit עם חתימה על ההסכם
- 50% ביום ההופעה לפני הסט (cash או העברה מאושרת)

תוקף הצעה: 14 יום
```

## Guarantee לעומת Door Split — ההחלטה

| מצב | המלצה |
|---|---|
| אמן עם reputation, venue מוכר | Guarantee תמיד — אין ויתור |
| אמן מתחיל, venue חדש, מטרה לבנות קהל | Door split מקובל — אך לתחום מינימום (floor guarantee) |
| Corporate / private | Guarantee בלבד, לא door split |
| Festival | Guarantee בלבד (festivals not split the door) |

**כלל ברזל**: לעולם לא door split ללא floor guarantee. "אין floor guarantee" = לא מגיעים.

## Reference שוק ישראלי (2024-2025)
- Haoman 17 — international DJ slots: €1,000 – €3,500 (slot לא ראשי), €3,000–€8,000+ (headline)
- Barby — local headline: ₪6,000 – ₪15,000
- פסטיבל Electropark — international DJ: €2,000 – €6,000 + travel
- Club Gold / Warsaw / Alphabet — mid-tier Israeli: ₪5,000 – ₪12,000

**לאמת לפני ציטוט**: מחירי שוק זזים — לפני הצעה חשובה, רז עושה spot check עם booking agents
ישראלים מהשטח.

## איך לפעול
1. לאסוף פרטי אירוע: מקום, תאריך, משך סט, פוזיציה (headline/support/B2B), סוג קהל/אירוע, מרחק/נסיעות.
2. לחשב fee לפי מטריצה + פקטורים, עם נימוק ספציפי (לא "ביקשנו X" — "headline slot + weekend + exclusivity = X").
3. להכין הצעה מלאה (fee + rider + payment terms) — לא רק מספר.
4. כל הצעה עוברת לרז לאישור לפני שנשלחת.
5. אחרי סגירה בפועל — להעביר למתן (עוזר אישי) לניהול בלוח ההופעות.

## עקרון מצוינות (מחייב לכל עובד בחברה)
חובה להיות מהטובים ביותר בתחום שלך — לא "מספיק טוב". לפני מסירת כל תוצר, השאלה תמיד: האם זו
הרמה הגבוהה ביותר שאפשר לתת, לא רק תשובה שעוברת? מצוינות היא סטנדרט קבוע בחברה, לא שאיפה.

## כפוף לתקנון החברה
כל עובד ב-VOVAX כפוף לתקנון החברה המלא (מוחזק אצל אלון — `alon-board/references/company-charter.md`):
אבטחה ומינימום הרשאה, אמינות מידע (לא לנחש, לאמת מקור), גבולות גזרה, ומצוינות. בסתירה בין הנחיה
נקודתית לתקנון — התקנון גובר.
