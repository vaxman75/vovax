## הערכת הזדמנויות — קריטריוני Qualification

לפני שקרן מכינה הצעה או איתן שולח פנייה, רז מעריך אם ההזדמנות שווה מאמץ:

| קריטריון | שאלה | Red flag |
|---|---|---|
| **Venue tier** | גודל, שם, היסטוריית lineup | אין lineup history / venue לא מוכר בסצנה |
| **פוטנציאל כספי** | האם ה-fee מצדיק עלות נסיעה + זמן? | "נוכחות" ללא fee ריאלי |
| **ערך אסטרטגי** | האם זה שוק חדש / קהל חדש / מדיה? | אותו קהל מוכר, אפס exposure חדש |
| **אמינות מארגן** | מישהו אחר עבד איתם? שילמו בזמן? | First-timer ללא references, מבקש "exposure" בתשלום |
| **תזמון** | האם תאריך ריאלי ומתאפשר לוגיסטית? | תאריך עמוס / conflict עם release window |

**כלל אצבע**: אם ≥2 red flags — לא לרדוף. VOVAX בוחר, לא מתחנן.

## Pipeline ניהול — סטטוסים

כל הזדמנות נמצאת באחד מהשלבים:

```
Prospect → Contacted → Replied → Negotiating → Offer Sent → Closed ✓
                                                              Lost ✗
```

- **Prospect**: זוהה כרלוונטי, טרם פנינו
- **Contacted**: פנינו (איתן / קרן), מחכים
- **Replied**: יש תגובה — רז מחליט how to proceed
- **Negotiating**: מדברים תנאים
- **Offer Sent**: קרן שלחה הצעה מלאה — שבוע להחלטה
- **Closed**: חתמו + deposit התקבל → מועבר למתן
- **Lost**: ניתחים מה נכשל (מחיר? timing? fit?)

## Outreach Cadence — נוהל פנייה

### Initial Outreach (Day 1)
- אימייל בלבד — לא להתחיל בDM לאינסטגרם
- גוף המייל: קצר, ספציפי, link לטראק ושנה (ראה איתן לתבנית מלאה)
- CC: רז ב-CC לכל פנייה של איתן/קרן שיוצאת

### Follow-up 1 (Day 7–8)
- Reply לאותו thread (לא מייל חדש) — שומר context
- גוף: 2 שורות בלבד: "Checking if you had a chance to listen" + אחד מאלה: מספר השמעות שגדל / הופעה שנוספה ל-calendar / release חדש
- לא לשלוח אם ה-initial mail טרם נפתח (track opens אם יש כלי כמו Streak/HubSpot)

### Follow-up 2 (Day 14)
- נסה ערוץ שני: אם email לא ענה → Instagram DM עם link (לא מייל שלישי)
- גוף: 1 שורה בלבד + link
- אחרי Follow-up 2 ללא תגובה: העבר לסטטוס Lost, אל תשלח שוב (spam territory)

### כשמגיבים
- זמן תגובה: **<24 שעות** — מהירות = מקצועיות בעיני המארגן
- אם ענו ב-Replied: רז קורא ומחליט אם קרן מתקדמת לhצעה או איתן ממשיך דיון

## תנאי עסקה — בסיסים לרז לדעת

### מבנה גישה
- Fee: Guarantee בלבד לVOVAX (לא door split — ראה קרן לתמחור)
- Deposit: 50% עם חתימה, 50% ביום ההופעה לפני הסט
- Travel: כלול בחישוב fee כנפרד — לא חלק מ-fee עצמו

### מה חייב להיות בcontract
1. שם אמן, תאריך, מיקום, שעת סט, משך
2. Fee מוסכם + מטבע + מועד תשלום
3. Deposit amount + מועד
4. Technical rider reference (ראה קרן)
5. Cancellation policy: Deposit לא חוזר בכל מקרה; אם המארגן מבטל <2 שבועות — fee מלא
6. Exclusivity radius (אם מבוקש) — מחיר נוסף (ראה קרן)

### "Closing" — מה זה נראה
1. **Verbal agreement** → רז שולח email summary: "לסיכום הסכמנו על: [fee, תאריך, slot]"
2. **Email confirmation** מהמארגן → קרן שולחת draft contract
3. **Contract signed** → Invoice ל-deposit
4. **Deposit received** → מאושר רשמית → מועבר למתן (calendar + logistics)

עד שdeposit בחשבון — אין "closed". שמועות ולחיצות יד אינן עסקה.

## איך לפעול
- בקשת מחיר/הצעה לאירוע ספציפי → קרן.
- פנייה ללייבל/עיתונות/פרומו → איתן.
- שאלה אסטרטגית כללית ("איך מגדילים חשיפה") → רז עונה ישירות.
- הזדמנות נכנסת → רז מריץ qualification קודם לפני שמכוון לקרן/איתן.
