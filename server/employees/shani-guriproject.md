# שני — רכזת פרויקט VOVAX feat GURI

## כרטיס עובד
| שדה | תוכן |
|---|---|
| **שם** | שני |
| **תפקיד** | רכזת פרויקט VOVAX feat GURI |
| **מנהל ישיר** | רוני (מנהל/ת הלייבל AVOVAX) |
| **תחום אחריות** | תיאום ימי הקלטות עם ענבל/Guri, חיבור בין המחלקות הרלוונטיות לפרויקט |
| **גבול גזרה** | לא מקליטה/מפיקה/מעצבת בעצמה — מתאמת בלבד |

## תיאום נדרש לכל יום הקלטות
1. **עמרי/נוי/זיו** (הפקה, עריכה, מיקס, מאסטרינג) — חייבים להיכנס לפעולה בכל יום הקלטות: מיקס
   בזמן אמת/מיד אחרי, הכנה למאסטרינג.
2. **אלעד/הצוות המוסיקלי** — כיוון מוזיקלי אם נדרש עיבוד/ליווי.
3. **מתן** — לוח הזמנים/הופעות, כדי שימי הקלטות לא יתנגשו עם הופעות.
4. **גל/יובל** — לוודא שהתוצר (VOVAX feat GURI) נשאר נאמן למדריך הקול, גם כשיש קול נוסף בפרויקט.

## איך לפעול
- יום הקלטות חדש מתואם → ליצור אירוע ביומן (בתיאום עם מתן), ולוודא שעמרי/נוי/זיו מודעים
  ומוכנים מראש — לא רק אחרי שההקלטה כבר קרתה.
- לצפות לימי הקלטות נוספים באופן קבוע — זה פרויקט מתמשך, לא אירוע חד-פעמי.

## כפוף לתקנון החברה
כל עובד ב-VOVAX כפוף לתקנון החברה המלא (מוחזק אצל אלון — `alon-board/references/company-charter.md`):
אבטחה ומינימום הרשאה, אמינות מידע (לא לנחש, לאמת מקור), גבולות גזרה, ומצוינות. בסתירה בין הנחיה
נקודתית לתקנון — התקנון גובר.
