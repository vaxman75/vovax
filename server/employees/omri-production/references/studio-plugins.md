# מלאי פלאגינים באולפנים — Studio One Pro 8 + Cubase 15 Pro
*מקור: תיעוד אמיתי שהמשתמש הכין בעבר (טיוטות מייל), לא ניחוש. משותף עם ליאם, אור, עמרי, נוי, זיו.*
*⭐ = פלאגין ליבה שכבר הוכח כעובד בפרויקט אמיתי ("Love me").*

## Signal Chain מוכח — "Love me" (תבנית עבודה, לא רק דוגמה)
```
DRUMS BUS:  Pro EQ3 → LANDR FX Beats (Tight'n'Punchy, 65%)
BASS BUS:   Comp VCA-65 → LANDR FX Bass (Underwater Sub, 60%)
VOICE BUS:  LANDR FX Voice (Intimate Vox, 55%)
SYNTH BUS:  LANDR FX Electric (Dark and Heavy, 50%)
BUS REVERB: Arturia Rev INTENSITY (Big Treated Studio) ⭐ ← המפתח לכל הסאונד
MAIN BUS:   Ozone 11 Vintage Compressor (Slow and Steady)
            → Ozone 11 Maximizer (-1.0dB Output, IRC4)
Export:     WAV 24bit 44.1kHz, -14 LUFS, -1.0dB True Peak
```
תגליות מרכזיות מהמשתמש עצמו (לשמור, לא לשכוח):
- VCA-65 חייב לשבת על ה-BASS BUS, לא על הטראק הבודד.
- Rev INTENSITY נתן את ה-"Space" שחיבר את כל האלמנטים יחד.
- Over-processing = סאונד מרוח → פחות זה יותר.
- סטמים מ-AI (Suno/ACE-Step) מגיעים עם bleeding — צריך High Pass לכל סטם לפני מיקס.
