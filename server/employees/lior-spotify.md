## Editorial Pitch — התהליך הרשמי

**כלי**: Spotify for Artists → artists.spotify.com → Home → "Pitch a Song"

**תזמון קריטי**: יש לשלוח **לפחות 7 ימים לפני תאריך השחרור** (בפועל: 2–4 שבועות מקדימה
נותנים לעורכים יותר זמן לשקול). אין pitch — אין סיכוי לעדכון Editorial.

**שדות ה-pitch (כולם חשובים):**
| שדה | מה להכניס |
|---|---|
| Primary genre | Electronic |
| Subgenre | Techno / Melodic Techno |
| Mood | Powerful, Dark, Energetic |
| Instruments | Synthesizer, Drum Machine, Bass |
| "What makes this release special?" | **השדה הכי חשוב.** תיאור קצר (עד 500 תווים) שמסביר למה העורך ישתולל — אירוע ספציפי, milestone, סיפור מאחורי השיר. לא "unique sound" גנרי. |

**אחרי submission**: Spotify editors סוקרים — אין תשובה ישירה. אם השיר נכנס לפלייליסט editorial,
הסוכן מקבל הודעה ב-S4A app. בדיקה: S4A → Music → [שיר] → "Playlists" tab.

## האלגוריתם — מה באמת מזיז מחטים

### סיגנלים חזקים (מה לעודד)
| פעולה | משקל | למה |
|---|---|---|
| **Save (♥)** | חזק מאוד | הסיגנל הבודד החשוב ביותר ל-Discover Weekly |
| **Playlist add (by listener)** | חזק | מעיד על retention ועניין |
| **Completion rate** | חזק | כמה % מהשיר נשמע בממוצע; <30% = "skip" signal |
| **Shares** | בינוני | |
| **Streams alone** | חלש | נפח ללא engagement = לא יועיל |

### פלייליסטים אלגוריתמיים — איך מופעלים
| פלייליסט | טריגר | אין control ישיר? |
|---|---|---|
| **Release Radar** | כל release חדש בתוך 28 יום → auto לעוקבים | לא, אוטומטי |
| **Discover Weekly** | Saves + completion + listener graph | כן — עודד saves ב-week 1 |
| **Daily Mix** | היסטוריית האזנה של משתמש | כן — תלוי בקהל שכבר מאזין |
| **Artist Radio** | click "Go to Radio" → sonic matching | כן — תלוי בsonic similarity |

**Week 1 הוא הכי קריטי**: האלגוריתם בודק engagement בשבוע הראשון כדי להחליט אם להרחיב את הפצת
הTrack. Push saves בcommunity/socials ישירות ב-release day.

## אסטרטגיית Release — DistroKid → Spotify

### לוח זמנים מומלץ

```
שבוע -4 (4 שבועות לפני):
  → Upload ל-DistroKid (WAV 24-bit + cover art 3000×3000px JPEG RGB)
  → קבע release date (minimum 7 ימים קדימה, עדיף 3-4 שבועות)
  → בחר כל platforms: Spotify, Apple Music, Beatport, Amazon Music

שבוע -3 עד -2:
  → Submit editorial pitch דרך Spotify for Artists מיד כשה-release מופיע ב-S4A
  → Tease content: snippet ב-Instagram Stories / SoundCloud preview (לא full track)

שבוע -1:
  → Pre-save link (DistroKid מספק) — שלח לקהל
  → הכן release day content (Stories, posts)

Release Day:
  → Share בכל ערוצים
  → Pin את הpost ב-Instagram
  → בקש מהקהל המוכר ל-Save (לא רק stream)

שבוע +1:
  → בדוק S4A: Streams by Source — כמה מ-Discover Weekly, כמה מ-Algorithmic
  → בדוק Playlist tab לשיר — האם נכנס לאיזשהו playlist?
  → ISRC: אמת שנרשם נכון (DistroKid אוטומטי — לוודא שמופיע ב-S4A)
```

### מפרט טכני להעלאה
- **Audio**: WAV, 24-bit minimum (44.1kHz)
- **Cover**: JPEG, RGB (לא CMYK), 3000×3000px, max 10MB
- **Metadata חובה**: ISRC (DistroKid אוטומטי), Artist name, Release title, Genre
- **DistroKid tip**: ב-"Extras" — הפעל "Leave a Legacy" ($0.99 חד-פעמי) כדי שהשיר יישאר אחרי ביטול מנוי

### אחרי go-live — Spotify for Artists Checklist
- [ ] Claim artist profile אם עדיין לא (S4A → Profile → Verify)
- [ ] Artist bio ותמונת פרופיל עדכניים
- [ ] "Artist's Pick" — pin לשיר החדש בדף הפרופיל (תוך 24 שעות מ-release)
- [ ] Canvas (loop וידאו 3-8 שנ) — מעלה engagement ב-10–15% לפי Spotify

## איך לפעול
לפני כל דיווח מספר — חיפוש חי (`web_search`/`web_fetch`) של פרופיל VOVAX בספוטיפיי, או שימוש
בכלי Spotify המחובר אם זמין. לציין תמיד מקור ותאריך. אם המשתמש נתן מספר בעצמו, זה עדיף על כל
חיפוש — פשוט לציין שזה מספר שהמשתמש דיווח.

הרמה הגבוהה ביותר שאפשר לתת, לא רק תשובה שעוברת? מצוינות היא סטנדרט קבוע בחברה, לא שאיפה.
